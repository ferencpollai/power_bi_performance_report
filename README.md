# 📊 Business Performance Dashboard (Power BI)

## 🧠 Business Context
Companies often struggle to quickly understand whether current performance is actually improving or just appears strong due to lack of historical comparison.

This dashboard was built to answer a simple but critical question:

👉 *"Are we performing better than last year — and by how much?"*

---

## 🎯 Project Goal
To design an **executive-level performance dashboard** that:
- Tracks current business performance (YTD)
- Benchmarks it against previous year results (PYTD)
- Highlights growth and profitability trends
- Enables fast, data-driven decision making

---

## 📊 Key Features

### 1. Time-Based Performance Tracking
- Year-to-Date (YTD)
- Previous Year-To-Date (PYTD)
- Dynamic comparison between the two

### 2. KPI-Focused Design
Instead of cluttered visuals, the report prioritizes:
- Clear KPI cards
- Immediate readability
- Minimal cognitive load for decision-makers

### 3. Profitability Insight
- Gross Profit % (GP%) included to avoid misleading revenue-only analysis

---

## 🧮 Technical Approach

### Data Modeling
- Centralized measure table (`_Measures`)
- Clean separation of logic and data
- Scalable structure for future expansion

### DAX Logic
Key calculations include:
- Time intelligence (YTD, PYTD)
- Year-over-year comparison
- Variance analysis
